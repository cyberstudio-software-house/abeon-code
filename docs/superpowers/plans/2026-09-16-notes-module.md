# Notes Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add project-scoped and global plain-text notes in one reusable Tauri window per project, opened from a new active-project toolbar.

**Architecture:** Persist notes in the existing SQLite database and expose typed CRUD commands through the established Rust → Tauri → `lib/tauri.ts` boundary. Extend query-string window routing with a notes mode, then render a dedicated split-view React shell whose local editor state guards every destructive navigation and native window close.

**Tech Stack:** Rust, rusqlite, ts-rs, Tauri 2, React 19, TypeScript, Tailwind 4, Vitest, Testing Library

**Spec:** `docs/superpowers/specs/2026-09-16-notes-module-design.md`

## Global Constraints

- All code identifiers are English; all user-facing copy is Polish.
- Do not add code comments.
- Use SQLite in the existing AbeonCode database; do not add a storage dependency.
- Notes contain a required title and plain-text content, with explicit save only.
- Keep the existing terminal and editor actions in the left sidebar.
- Allow one notes window per project and include `notes-project-*` in Tauri capabilities.
- Do not add Markdown, search, tags, autosave, cross-window synchronization, or conflict detection.
- Every implementation task ends in a Conventional Commit without co-author metadata.

Create `openNotesWindow.ts` with this flow:

```ts
export async function openNotesWindow(projectId: number, projectName: string): Promise<void> {
  const label = notesWindowLabel(projectId);
  const existing = await WebviewWindow.getByLabel(label);
  if (existing) {
    await existing.setFocus();
    return;
  }

  const win = new WebviewWindow(label, {
    url: buildNotesWindowUrl(projectId),
    title: `Notatki — ${projectName}`,
    width: 920,
    height: 680,
    minWidth: 720,
    minHeight: 520,
    titleBarStyle: 'overlay',
    hiddenTitle: true,
  });

  await win.once('tauri://error', (event) => {
    console.error('[notes] window create failed', event);
    toast.error('Nie udało się otworzyć okna notatek');
  });
}
```

Add `"notes-project-*"` to the `windows` array in `capabilities/default.json`.

```ts
export type NoteDraft = {
  id: number | null;
  title: string;
  content: string;
  savedTitle: string;
  savedContent: string;
};

export const emptyNoteDraft = (): NoteDraft => ({
  id: null,
  title: '',
  content: '',
  savedTitle: '',
  savedContent: '',
});

export const noteToDraft = (note: Note): NoteDraft => ({
  id: note.id,
  title: note.title,
  content: note.content,
  savedTitle: note.title,
  savedContent: note.content,
});

export const isNoteDraftDirty = (draft: NoteDraft | null): boolean =>
  draft !== null && (draft.title !== draft.savedTitle || draft.content !== draft.savedContent);
```
