# Supervisor Question Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the supervisor's question card readable (own heading, accent frame, larger question), move it to a panel under the session terminal, and give the user a rolling 5-minute countdown while they are active with the card on screen.

**Architecture:** The backend keeps owning the deadline: a new `supervisor_extend_card` command pushes a `Grace` menu's deadline to `now + 5 min` and marks it extended; menus stop pausing on focus. The frontend card calls that command (throttled) on window activity while visible, and `TabPanel` measures the card and insets the session layer's `bottom` so the terminal shrinks instead of being covered.

**Tech Stack:** Rust (Tauri 2, tokio, ts-rs), React 19 + Zustand 5 + Tailwind 4, Vitest + jsdom.

**Spec:** `docs/superpowers/specs/2026-11-16-supervisor-question-card-design.md`

## Global Constraints

- Run every command from `DesktopApp/`. Frontend tests: `npx vitest run --maxWorkers=3 <files>` (plain `npm test` flakes under load). Rust: `npm run test:rust` or `cargo test --manifest-path src-tauri/Cargo.toml <filter>`. Lint: `npm run lint` must report zero errors.
- Identifiers English; UI copy Polish, exactly: „Pytanie sesji”, „Agent odpowie za M:SS”, „Agent analizuje pytanie…”.
- No code comments.
- Commits: Conventional Commits, `feat(desktop):` / `fix(desktop):` / `docs(desktop):` / `test(desktop):`; **no** `Co-Authored-By` and **no** `Claude-Session` trailer.
- Work directly on local `main`; no push.
- `ACTIVE_CARD_GRACE` = 5 min (300 s), constant, no setting. Frontend extend throttle = 10 s, leading edge.
- Unchanged: `MENU_HOLD_CAP` (570 s), the 600 s hook timeout, `DECISION_WINDOW`, human-prompt cancellation, attention, Discord routing, `TurnEnded` pause.
- Content layers in `TabPanel` must keep their DOM parent and key; only inline style may change (see `DesktopApp/CLAUDE.md` → Gotchas).
- `src/types/*.ts` from ts-rs are regenerated by `cargo test`, never edited by hand.

## Review Focus

- Activity while the card's tab is hidden must not extend it (the 60 s rule for unseen cards) — Task 3 test `does nothing while disabled`.
- Activity while the card is `withSupervisor` must not call the backend — Task 3 test `asks for more time only while visible in grace`.
- Switching to another tab and back while a card exists must not resize the terminal — Task 4 test `keeps the inset on a hidden tab`.
- After the card is answered or released the terminal must get its full height back — Task 4 test `drops the inset when the card goes`.
- A failing extend call (core not running, card just answered) must stay silent: no toast, no unhandled rejection — Task 3 test `ignores a failed call`.
